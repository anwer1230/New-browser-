# 🌐 متصفح كروم الذكي + بحث ذكي عن الفيديوهات المترجمة (Chrome Clone Browser)

متصفح ويب متكامل بواجهة Google Chrome حقيقية، يتصل بجوجل ومواقع الترجمة مباشرة، ومزود بطبقة ذكية لاستخراج الأكواد وإبراز الفيديوهات ذات الترجمات العربية.

## 🏗️ هيكل المشروع
```
chrome-clone-browser/
├── index.html              # الواجهة الرئيسية (مثل كروم)
├── styles.css              # تصميم كروم
├── js/
│   ├── browser.js          # المنطق الرئيسي
│   ├── tabs.js             # إدارة التبويبات
│   ├── omnibox.js          # شريط العنوان
│   ├── search-engine.js    # الاتصال بجوجل + الفلترة
│   ├── subtitle-detector.js# كشف الترجمات العربية
│   └── ui-renderer.js      # عرض النتائج
└── assets/
    └── icons/              # أيقونات
```
